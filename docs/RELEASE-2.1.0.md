## 2.1.0 原生版

- 新增「武器合成」页，显示当前游戏和已加载 DLC 的武器配方、素材名称、等级条件和图标，可切换中英文。武器合成与指定奖励在每次连接游戏后共用一次自动加载，之后可手动刷新。
- 「局外金币」支持当前冒险的独立钱包。在对应的单人主菜单设置并保存。
- 一击必杀补齐红色死神及多种精英、首领和特殊敌人的受击路线，并减少密集命中时的重复判断。
- 新增普通宝箱五件装备开关，改善它和跳过宝箱动画在游戏加速时的触发时序。特殊宝箱仍沿用原有奖励规则。

支持 Steam Build **25984009**、游戏 **1.16.111**、Windows x64 单人模式。升级时请退出游戏和旧修改器，再启动游戏并连接新版。

下载单 EXE 后，可用 `SHA256SUMS.txt` 核对文件。GitHub 构建证明的核验步骤见[安全说明](https://github.com/beason409/VampireSurvivorsTrainer-Native/blob/v2.1.0/docs/SECURITY.md)。作者 **Beason9527**。

## 2.1.0 Native Edition

- Browse weapon recipes for the base game and loaded DLC with localized names, level requirements and icons. Recipes and targeted rewards share one automatic load per connection, with manual refresh available.
- Edit the active adventure's separate menu gold balance.
- Extend instant-kill coverage to Red Death and more verified elite, boss and special enemies. Reduce repeated checks for dense hits.
- Add a five-equipment option for ordinary chests and improve its timing with chest-animation skipping at increased game speed.

Supports Steam Build **25984009**, game **1.16.111**, on Windows x64 in single-player mode. On upgrade, exit the game and the old trainer before reconnecting. Verify the EXE using `SHA256SUMS.txt` and the GitHub build attestation.
