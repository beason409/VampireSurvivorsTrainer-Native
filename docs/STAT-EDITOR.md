# 属性编辑说明

当前使用说明适用于桌面与配套插件 **1.0.0**。

“属性编辑”覆盖当前角色本局使用的计算结果或临时次数，不购买永久强化，不改永久强化购买记录，不把目标值写入存档。原有七项常用功能默认 F1～F7，可独立改绑；永久金币按钮继续保留。永久金币操作及安装备份要求见 [README](../README.md)。

属性页显示 23 项本局临时覆盖。“封印”属于局外收藏，已从界面移除，不提供本局覆盖或快捷键。具体行是否可操作，仍取决于配套插件、当前游戏版本和角色是否已进入关卡。接口接入不代表实机验收完成，当前验证结果以 [VALIDATION.md](../VALIDATION.md) 为准。

## 使用与读数

1. 连接本版配套插件并进入关卡，在“属性编辑”页搜索属性名、分类或单位。
2. 输入目标值，点击该行“开启”。尚未开启时编辑输入框只修改目标，不会发送覆盖请求。
3. 已开启时修改目标值，点击“应用”提交。请求等待期间暂时锁定操作；开关、读数以插件确认后的状态为准。
4. 点击该行“关闭”恢复此项正常计算。“关闭全部属性”只关闭属性覆盖；窗口上方“关闭全部”同时关闭原有七项持续功能和全部属性覆盖。

“正常值”是本局不应用该项覆盖时的当前值，包含角色、永久强化、装备和正常升级的影响；“当前生效值”是插件当前读回的实际值。“目标值”是输入或已提交的目标，并不等于当前剩余次数。没有有效读数时显示 `—`；“万能统一加成”是四项设置的组合，没有独立的单项正常值和生效值。

角色、装备与本局正常升级仍会更新正常值。关闭覆盖时以最新正常计算结果为准，不会用开启前的旧数值撤销后续正常升级。生命上限覆盖不会自动补满生命；恢复后的生命值仍受正常生命上限约束。

## 属性快捷键

23 项属性各有一个默认“未绑定”的快捷键按钮，与七项常用功能合计 30 项独立绑定。点击按钮后按新键，支持 F1～F24、小键盘键和受支持的 Ctrl / Alt / Shift 组合。两页统一检查冲突，冲突时保留原绑定并继续等待输入；Delete / Backspace 清除，Esc 取消。已保存的绑定或清除状态会在下次启动保留。

属性热键只切换该行开关：关闭时按当前目标值开启，已开启时再按会关闭；已开启后编辑目标值仍需点击“应用”。只有游戏在前台、已进入关卡、该项受支持且没有操作等待时才执行，长按不会连发。按住键切回游戏时会先重新待命，需要松开再按。

永久金币读取/设值和宝箱/指定升级不提供热键；“封印”也不在绑定列表中。快捷键保存在本机窗口设置中，“说明与来源”提供打开数据目录的按钮，不显示个人绝对路径。游戏安装目录由主界面另行识别。

## 百分比与原有倍率

力量、弹速、持续时间、范围、移动速度、幸运、经验成长、金币收益和诅咒采用加成百分比：目标 `+100%` 对应系数 `1 + 100/100 = 2`。这是直接设定本局该项角色加成；正常计算值在后台保留，关闭后恢复。

“力量加成”与“伤害倍率”（默认 F4）作用于不同环节，继续相乘。例如忽略其他机制时，基础伤害 10、力量目标 `+100%`、伤害倍率 3 倍，结果为 `10 × 2 × 3 = 60`。武器自身伤害计算与游戏原有机制仍继续执行。经验成长与“经验倍率”（默认 F3）、移动加成与“移动倍率”（默认 F5）同样可组合。

“冷却缩减”使用 `1 - 缩减百分比/100`：`90%` 对应系数 `0.1`。武器自身下限与原有机制仍可能约束最终效果；“快速冷却”（默认 F6）可以同时开启，并继续将已支持武器的普通攻击冷却按原规则压至至多 0.1 秒。原有九种基础武器范围见 [README](../README.md)。

“万能统一加成”把相同目标百分比分别设给力量、弹速、持续时间和范围，不会叠加四次。单独开启的属性优先：例如万能设 `+100%`、单独力量设 `+200%` 时，力量使用 `+200%`，其余三项使用 `+100%`；关闭单独力量后，若万能仍开启，力量重新使用万能目标。

## 拾取范围与游戏面板

拾取范围使用实际半径。程序将临时覆盖对象应用于游戏的拾取形状，并单独保留正常半径。覆盖期间获得的正常装备加成继续更新正常半径；关闭后按最新正常半径恢复。

游戏已经打开的通用属性数值面板可能保留缓存，下一次打开面板时刷新。因此面板旧值不能单独用于判断后台是否已恢复。通用数值面板与升级页资源按钮分别处理；重选、跳过、排除按钮会根据当前剩余次数刷新。

## 次数预算与概率

复活、重选、跳过、排除使用独立临时预算。开启时以目标值建立预算，游戏正常消耗这份临时次数；每帧或每次读数不会把已经消耗的次数补回目标。

例如原本剩余重选 2 次，临时目标设为 10，使用 3 次后当前生效值为 7，目标框仍可显示 10。关闭后恢复原本的 2 次；如果覆盖期间正常升级为原次数增加了 1 次，关闭后恢复为 3 次。复活的临时总次数与临时已用次数也独立于原记录，关闭时还原原记录，并保留本局正常升级的更新。

“次数保留概率”与“去牙概率”在窗口使用 `0～100%`，后端写入本局临时浮点比例 `0～1`，例如 `50% → 0.5`、`100% → 1`。正常升级仍更新保留的原概率值，关闭后恢复原值及其正常升级。

去牙使敌人无法造成接触伤害，通过游戏后续敌人生成流程生效。开启不会倒改已生成的普通敌人；关闭也不会把已经去牙的敌人倒改成可造成接触伤害的敌人。

## 关闭、断连与保存

正常退出修改器会请求关闭所有持续效果和属性覆盖。断连或超过 3 秒未收到心跳时，插件也会关闭覆盖；退出游戏后本局临时对象随进程结束。重新连接不会自动恢复开启状态。

这些恢复操作撤销的是临时覆盖。游戏正常产生的收益、进度、成就，以及已经通过“设置金币”保存的永久钱包结果，仍按游戏原有保存规则处理。安装、金币操作和恢复备份的要求保持不变，见 [README 的备份说明](../README.md#备份更新和卸载)。
