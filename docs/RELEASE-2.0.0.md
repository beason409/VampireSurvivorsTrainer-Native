## 2.0.0 原生版

- Windows x64 单 EXE，内置中英文界面。先开游戏或修改器都可以自动连接，也可以手动选择游戏目录。
- 提供 9 项常用功能和 23 项本局属性，支持自定义开关快捷键、指定奖励、游戏加速与跳过普通宝箱动画。「局外金币」页可在普通模式单人主菜单设值并保存。
- 奖励图标从已连接的游戏按需读取。窗口最小化时减少界面刷新，后端使用 Windows 无损压缩。

从 1.0.0 切换时，请在游戏退出后使用旧版的「维护与备份」卸载旧配套插件。保留旧版数据目录中的备份。之后从 Steam 启动游戏并打开新版即可。

适配 Steam Build **25984009**、游戏 **1.16.111**、Windows x64 单人模式。下载 EXE 后可用 `SHA256SUMS.txt` 核对文件，并通过 GitHub 构建证明核对来源。核验步骤见 [安全说明](https://github.com/beason409/VampireSurvivorsTrainer-Native/blob/v2.0.0/docs/SECURITY.md)。

作者 **Beason9527**。

## 2.0.0 Native Edition

A single Windows x64 executable with automatic connection, manual game-folder selection, and a Chinese/English interface. Includes run stats, effect hotkeys, targeted rewards, game speed, chest-animation skipping, and save backup tools. Supports Steam Build **25984009** in single-player mode. Check the download against `SHA256SUMS.txt` or verify its GitHub build attestation.
