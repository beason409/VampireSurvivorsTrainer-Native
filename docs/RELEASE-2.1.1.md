## 2.1.1 原生版

- 普通模式和当前冒险都可在各自的单人菜单直接设置并保存局外金币，无需提前备份。
- 修复直接双击修改器时弹出命令行窗口的问题。

支持 Steam Build **25984009**、游戏 **1.16.111**、Windows x64 单人模式。升级时先退出游戏和旧修改器，再启动游戏和新版。Steam 可以保持开启。

下载单 EXE 后，可用同页的 `SHA256SUMS.txt` 核对文件。GitHub 构建证明的核验步骤见[安全说明](https://github.com/beason409/VampireSurvivorsTrainer-Native/blob/v2.1.1/docs/SECURITY.md)。作者 **Beason9527**。

## 2.1.1 Native Edition

- Set and save normal or adventure gold directly from its solo menu without a pre-launch backup.
- Fix the console window that appeared when opening the trainer.

Supports Steam Build **25984009**, game **1.16.111**, on Windows x64 in single-player mode. Exit the game and the old trainer before opening the new version. Verify the EXE using the accompanying SHA-256 file and GitHub build attestation.
