# 数据与权限

Vampire Survivors Trainer 由 Beason9527 开发，供普通单人游戏使用。

- 程序识别当前运行的游戏和 Steam 安装信息，核对游戏文件。手动选择的目录仅用于本机连接。
- 语言、数值与快捷键设置保存在当前 Windows 用户的本地应用数据目录。展开的后端按 SHA-256 分目录缓存。
- 「维护与备份」将备份保存在修改器自己的本地数据目录。备份清单包含用于校验与还原的文件信息。恢复前会保存当前进度的保护快照。
- 修改操作通过限于当前用户与会话的本机命名管道传递，游戏主线程执行。快捷键只在游戏前台时接收。
- 修改器本身不上传账号、游戏数据或日志。Steam 登录和云同步由 Steam 管理。程序以当前用户权限运行。

备份、完整日志、真实游戏路径和生成的游戏接口均为本机数据。公开反馈前请移除账号、真实路径及其他个人信息。下载核验见 [安全说明](SECURITY.md)。
